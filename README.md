# Kamille
Kamille project for Xmas

Live site (latest version): https://fycodelab.github.io/Kamille/

Kamille Code LED — crée un programme CircuitPython pour une matrice NeoPixel 16x16 avec OpenRouter. La clé OpenRouter est entrée dans la page, jamais enregistrée ni publiée.

Versions (kept, never replaced):
- v2 (latest): https://fycodelab.github.io/Kamille/kamillev2.html — GPT-4.1 mini, token/cost counter
- v1: https://fycodelab.github.io/Kamille/kamillev1.html — GPT-4o mini
